# projet 001 :MON CV ,VITE + REACT



## 1.Création du projet
npm create vite@latest 001
j'ai choisie : framework 'React',Variante 'javascript',linter 'Esint'. 

## 2.Role des dossiers et chiffiers indispansables
1-src: code source de l'application ,la ou on travaille
2-src-main.jsx: Point d'entrée affiche le composant app dans le page
3-src-App.jsx:Composant principal qui assemble les autre composant
4-src-App.css: style du cv
5-vite.config.js:configuration de vite
## 3.Création des composants
les composant sont dans le dossier src
1-InfoPerso.jsx: affiche le nom ,le titre,l'email,le telephone et la ville
2-Competence: affiche la liste des competences avec ul et li
3--Experience.jsx: affiche les experiences 
## 4.assamblage
les trios composant sont importés et utilisés dans App.jsx
